# 阶段1 部署架构规格 · 数字人后端上算力云

> 决策日期：2026-09-14 ｜ 状态：已确认定为方案  
> 适用范围：电商「卖货直播」数字人系统；对应实训工单21（Ultralight 训练）+ 工单08（实时交互）

## 1. 决策结论

数字人重算力环节（LLM / TTS / 口型引擎 / SRS 推流）部署到算力云 GPU 实例；本地 RTX 5060 仅承担轻量角色：React 前端、FastAPI `/api/live` 路由、弹幕中继、以及原有商品/购物车 API。

**后端栈锁定（路线1·拼装自建，2026-09-15 确认）**：口型/交互框架用 **LiveTalking（lipku/livetalking）**，口型引擎用 **MuseTalk / Ultralight-Digital-Human**；**Fay 框架仅作可选快速原型验证，不进入正式交付**（工单08/21 明确点名 LiveTalking/MuseTalk/Ultralight，且需紧嵌现有电商前端）。对话大脑恒定走 **agicto 中转 deepseek-v4-flash**。

## 2. 算力云实例选型

- 起步：RTX 4090 24G（AutoDL 按量，约 ¥2–3/小时）
- 备选：A10 24G（性价比）/ L20 48G（多并发直播间）
- 地域：选华北/华东节点，离观众近 → 降网络往返延迟
- 策略：仅开播时段拉起实例，下播释放，避免 7×24 空烧

## 3. 部署拓扑

本地（RTX 5060 机器）

- React LiveSellPage（视频区 + 商品卡 + 弹幕区 + AI 标识）
- FastAPI `/api/live` 路由 + 弹幕中继
- 原有 商品 / 购物车 API

算力云 GPU 实例

- 对话大脑：agicto 中转（base_url https://api.agicto.cn/v1，模型 deepseek-v4-flash，¥2/¥8 per M tokens），云实例**不自部署 LLM**；云 GPU 只跑 TTS + 口型引擎 + SRS
- TTS / 声音克隆（Edge TTS 顶上；XTTS / GPT-SoVITS 做克隆）
- 口型引擎：MuseTalk 或 Ultralight-Digital-Human
- SRS 推流服务器

网络

- 云口型引擎输出 → RTMP 推到云 SRS
- 前端经 WebRTC（低延迟 <1s，首选）或 HLS 拉流
- 弹幕 / AI 回复：WebSocket over wss（加密）

## 4. 视频与协议

- 推流：口型引擎 → RTMP → 云 SRS
- 拉流：前端 `<video>` 用 WebRTC（首选）或 HLS 兼容
- 弹幕：wss 双向，消息格式见后续 Phase 2 接口契约
- 合规：前端常驻「AI 数字人主播 / AI 生成」标识（mockup 已含）

## 5. 环境修正（关键，否则跑不起来）

工单21 写的 `CUDA 11.7 + PyTorch 1.13.1` 是代码层冲突：现代 GPU（含云上 4090/5090 与本地 5060 Blackwell）均不兼容，必须升级：

- Python 3.10 / 3.11
- CUDA 12.4 + PyTorch 2.5+（cu124 预编译 wheel）
- 核心依赖：livetalking / MuseTalk / ultralight-digital-human / ollama / edge-tts / SRS

环境速查（云实例，复制即用）：

```bash
conda create -n dh python=3.10 -y
conda activate dh
pip install torch==2.5.0 --index-url https://download.pytorch.org/whl/cu124
pip install edge-tts
# SRS 用 docker 起（WebRTC 还需放通 UDP 8000）
docker run -p 1935:1935 -p 1985:1985 -p 8080:8080 -p 8000:8000/udp ossrs/srs:5
```
