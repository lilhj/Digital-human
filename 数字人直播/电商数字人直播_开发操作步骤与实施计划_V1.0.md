# 电商数字人直播开发操作步骤与实施计划

> 版本：V1.0  
> 项目目标：在现有电商直播页面中嵌入实时 AI 数字人，实现“数字人直播 + AI 对话 + 商品知识 + 弹幕互动 + 自动讲解”的完整 MVP。  
> 开发原则：**先打通最小闭环，再逐步增加商品、Agent、交易和规模化能力。**

---

# 一、项目最终目标

目前页面已经有：

- 数字人直播页面
- 左侧视频区域
- 右侧商品卡片
- 直播状态
- 弹幕/互动区域
- 加入购物车按钮

最终要实现：

```text
用户进入直播间
       ↓
数字人出现
       ↓
数字人主动介绍商品
       ↓
用户发送弹幕
       ↓
WebSocket 实时传给后端
       ↓
AI Agent 判断问题
       ↓
LLM 生成回答
       ↓
查询商品/库存/价格等真实数据
       ↓
生成适合口播的话术
       ↓
数字人实时说话
       ↓
用户可以继续互动
```

最终形成：

```text
┌──────────────────────────────────────────┐
│              AI 电商数字人直播            │
├───────────────────────┬──────────────────┤
│                       │    商品信息       │
│                       │                  │
│       数字人主播       │  Xiaomi 17 Max  │
│       WebRTC           │  ¥4799          │
│                       │  库存 128        │
│                       │                  │
├───────────────────────┴──────────────────┤
│                 直播互动                  │
│  用户：这个手机续航怎么样？                │
│  AI：这款配备8000mAh电池……                │
│                                          │
│  [输入弹幕.......................] [发送] │
└──────────────────────────────────────────┘
```

# 三、第一阶段：数字人显示

## 目标

先完成最简单的闭环：

```text
网页
 ↓
创建数字人 Session
 ↓
获取 WebRTC
 ↓
浏览器播放
 ↓
数字人出现
```

暂时不做：

- 商品知识库
- RAG
- 多 Agent
- 订单
- 自动直播
- 复杂后台

## 操作步骤

### Step 1：准备数字人服务

第一版建议使用成熟的云端数字人服务，例如：

- 腾讯云智能数智人
- HeyGen LiveAvatar
- 魔珐有光

第一阶段可以优先验证腾讯云路线。

需要准备：

```text
数字人账号
数字人形象
项目/形象 ID
API 凭证
```

**API Key、AccessToken 等敏感信息只能放后端。**

---

# 六、第四阶段：WebSocket 实时互动

这是正式进入“直播”的关键阶段。

## 目标

把：

```text
输入框 → HTTP → AI
```

升级成：

```text
浏览器
   ↕
WebSocket
   ↕
FastAPI
   ↕
LiveAgent
   ↕
数字人
```

---

## WebSocket 地址

```text
/ws/live/{room_id}
```

例如：

```text
/ws/live/room_001
```

客户端发送：

```json
{
  "type": "CHAT",
  "text": "8000mAh是真的吗？"
}
```

服务器返回：

```json
{
  "type": "AVATAR_SPEAKING",
  "text": "是的，这款产品的商品资料显示……"
}
```

---

## 消息类型

建议定义：

```text
CHAT
LIKE
PRODUCT_CHANGE
AVATAR_START
AVATAR_STOP
AVATAR_SPEAKING
AVATAR_LISTENING
AI_THINKING
SYSTEM
ERROR
```


# 二十二、开发时的几个关键原则

## 原则 1：数字人与大模型解耦

不要：

```text
LLM = 数字人
```

应该：

```text
LLM
 ↓
文本
 ↓
Avatar
```

这样以后可以更换：

```text
DeepSeek
Qwen
ChatGLM
GPT
自研模型
```

而不需要重新做数字人。

---

## 原则 2：业务事实与 LLM 解耦

不要：

```text
Prompt：
库存128
价格4799
```

应该：

```text
LLM
 ↓
工具调用
 ↓
业务 API
 ↓
真实数据
```

---

## 原则 3：先使用第三方数字人

第一版：

```text
第三方 Avatar
```

后面再：

```text
自研 Avatar
```

这样可以大幅降低第一阶段研发风险。

---

## 原则 4：先单直播间

不要一开始就：

```text
1000个直播间
```

先：

```text
1个直播间
1个数字人
1个商品
```

闭环跑通之后再扩容。

---

## 原则 5：任何时候都可以人工接管

必须设计：

```text
AI自动直播
       ↕
人工主播
       ↕
AI辅助
```

人工可以：

```text
暂停 AI
手动发话
手动切商品
手动回答
恢复 AI
```

这是商业化直播系统必须考虑的能力。
