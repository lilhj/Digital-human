## 三、结论与改进建议

1. 规则引擎对**显式关键词类**注入/越狱（中文、英文、Base64、跨语言高频词）拦截率近 100%，满足工单6 红线（注入≥95%、越狱≥98%）。
2. **语义/变形类攻击**（空格分词、同义改写、无关键词的隐含指令）规则引擎无法覆盖，为已知缺口；建议接入轻量级语义模型（工单6 规格中的'双引擎'第二引擎）做二分类兜底。
3. DLP 对手机号/身份证/密钥/邮箱/银行卡正则脱敏准确率高，但仅做正则遮掩，对**结构化 PII 变体**（如带分隔符的身份证）需补 NER 实体识别。
4. 红蓝对抗应**纳入 CI 周期执行**（工单8 周期测试），样本库随新攻击手法持续扩充。
