# 数字人直播项目 · 英文术语表

> 用途：本项目（电商「卖货直播」数字人系统）涉及的所有英文术语速查。
> 结构：英文词 → 是什么 → 在本项目干嘛用。

## 一、数字人引擎 / 口型驱动（让脸动起来）

| 英文 | 是什么 | 本项目干嘛用 |
|---|---|---|
| Ultralight-Digital-Human | 超轻量数字人开源项目（单段真人视频就能训练） | 工单21 指定方案：用 3–5 分钟真人视频训练个人数字人 |
| MuseTalk | 照片+语音→对口型说话视频的模型 | 口型引擎候选（轻量，8G/云都跑得动） |
| LiveTalking | 实时数字人对话框架，串起"大脑+语音+口型+推流" | 工单08 参考实现，支持切换 MuseTalk/Wav2lip/ERNerf |
| Wav2lip | 老牌唇形同步模型 | LiveTalking 兼容的口型引擎之一 |
| ERNerf | 基于 NeRF 的 3D 感数字人模型 | LiveTalking 兼容引擎，比 2D 照片重、更吃显存 |
| SyncNet | 判断音画是否对齐的模型 | 工单21 训练时可选项，提升口型同步质量 |

## 二、对话大脑（让数字人会聊天）

| 英文 | 是什么 | 本项目干嘛用 |
|---|---|---|
| Ollama | 本地跑大模型的工具 | 原计划云上自部署 Qwen 用，现改走 agicto API，可省 |
| Qwen / Qwen2-7B | 阿里通义千问（70 亿参数） | 原定本地对话大脑，已被 agicto 的 DeepSeek 替代 |
| DeepSeek / deepseek-v4-flash / -pro | 深度求索大模型 | 对话大脑选定 `deepseek-v4-flash`（便宜+强）；pro 太贵不用 |
| GLM / glm-5.3-flash | 智谱大模型 | 超低价备选对话大脑（¥0.4/¥1.4 per M tokens） |
| GPT-3.5-turbo | OpenAI 模型 | agicto 上能调，但比 DS flash 弱且贵，不推荐 |
| agicto / AGICTO | 中转站平台（base_url https://api.agicto.cn/v1） | 统一模型入口，对话大脑走它 |

## 三、语音（让数字人会说话）

| 英文 | 是什么 | 本项目干嘛用 |
|---|---|---|
| Edge TTS | 微软免费云端文本转语音 | 数字人配音，不占本地显存 |

## 四、音视频流媒体（让观众看到画面）

| 英文 | 是什么 | 本项目干嘛用 |
|---|---|---|
| SRS | 开源流媒体服务器（Simple Realtime Server） | 接收数字人推流，转成观众能看的流 |
| RTMP | 实时消息传输协议（推流用） | 口型引擎 → SRS 推流 |
| WebRTC | 浏览器实时通信（超低延迟） | 前端拉数字人流（<1 秒，首选） |
| HLS | HTTP 直播流（兼容好但延迟高） | WebRTC 的兜底拉流方式 |
| WebSocket / wss | 全双工实时通信（wss=加密版） | 弹幕和 AI 回复的实时收发 |

## 七、硬件 / 算力

## 八、其他概念词

- **pipeline（流水线）**：把"文本→语音→口型→推流"多步串起来的全链路。
- **streaming / inference（流式 / 推理）**：逐字实时输出 / 模型生成结果。
- **avatar（虚拟形象）**：数字人的"脸"。
- **lip-sync（唇形同步）**：嘴型和声音对齐。
- **danmu（弹幕）**：直播里飘过的观众评论。
- **IP**：品牌虚拟形象/知识产权，如想做的电竞虚拟主播。
- **persona（人设）**：给数字人设定的性格/话术身份。

## 一句话总览

脸(MuseTalk/Ultralight) + 脑(DeepSeek via agicto) + 声(Edge TTS/声音克隆) + 流(SRS/RTMP/WebRTC) + 壳(React/FastAPI) 五块。
